# Korean copy contract

## Hero

> 작업한 만큼, 증거와 다음 매출이 남습니다.

본문: 작업 전후를 남기고, 고객에게 확인받고, 동의된 기록을 우리 업체의 브랜드 자산으로 연결하세요. 청소·미용실·설치업의 고객 이력을 다음 상담과 재방문까지 이어주는 MyBiz.

CTA: `직접 체험하기` / `도입 상담하기` / `영상 크게 보기`.

## 업종과 체험

- 업종: 청소 / 미용실 / 설치·수리. 가발 / 인테리어는 `전용 영상 확장 예정`.
- 업종 제목: 보여줄 수 있는 결과가, 우리 업체의 경쟁력이 됩니다.
- 비교 제목: 말로 설명하기 전에, 전후로 보여주세요.
- 확인: 작업 결과를 확인했습니다. 이 확인은 결제 완료나 홍보 사용 동의를 뜻하지 않습니다.
- 동의: 선택 · 현재 버전의 사진을 업체 홈페이지 사례로 사용하는 데 동의합니다. 블로그·SNS 등 다른 채널 사용은 별도 동의가 필요합니다.
- 업체: 업체 검토 체험 · 현재 버전의 사례 초안을 검토하고 승인합니다.

## 홈페이지·후반부

- 완료한 작업이, 우리 브랜드의 이야기가 됩니다.
- 한 번의 작업을, 다음 기회로 연결하는 네 단계.
- 사진첩이 아니라, 업무 맥락이 남는 기록.
- 기록은 남기고, 사용 범위는 분명하게.
- 잘한 일을, 다음 고객에게 보여줄 준비를 하세요.

## 제공 상태

- 현재: 로컬 영상 재생, 업종 동기화, in-memory 확인/동의/검토 시연.
- 시연: 실제 결제·서명·저장·외부 게시를 실행하지 않는다.
- 확장 예정: 가발/인테리어 전용 영상과 실제 provider 연동.

## 금지 표현

- 확인을 결제 완료로 표현하지 않는다.
- 홈페이지 사용 동의를 블로그·SNS 동의로 확장하지 않는다.
- 해시를 진실·법적 효력의 자동 보장으로 표현하지 않는다.
- 확인하지 않은 고객 수, 만족도, 재계약률, 가격, 후기를 만들지 않는다.
- 연출 자료를 실제 고객 사례로 부르지 않는다.
