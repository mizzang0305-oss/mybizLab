# Korean copy contract

## 핵심 메시지

> 작업한 만큼, 증거와 다음 매출이 남습니다.

작업 전후 기록 → 고객 확인 → 별도 홈페이지 사용 동의 → 업체 검토 → 사례 후보의 순서를 설명한다.

## 금지 표현

- 확인을 결제 완료로 표현하지 않는다.
- 홈페이지 사용 동의를 블로그·SNS 동의로 확장하지 않는다.
- 해시를 진실·법적 효력의 자동 보장으로 표현하지 않는다.
- 확인하지 않은 고객 수, 만족도, 재계약률, 가격, 후기를 만들지 않는다.
- 연출 자료를 실제 고객 사례로 부르지 않는다.

실제 런타임 문구의 단일 소스는 `src/pages/mybiz-field/content/homepageCopy.ts`다.
