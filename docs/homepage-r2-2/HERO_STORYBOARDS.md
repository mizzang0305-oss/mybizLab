# Hero storyboards

모든 Hero는 12초, 24fps, 무음 loop다. 실제 `currentTime`이 아래 장면 문구를 바꾼다.

| 업종 | 0.0–6.1s 기록 | 6.2–9.2s 확인 | 9.3–12.0s 성장 |
| --- | --- | --- | --- |
| 청소 | 패브릭 의자 상태/범위 | 같은 면의 작업 결과 | 사례 후보 설명 |
| 미용실 | 연습 모델 스타일링 과정 | 완성 상태 확인 | 동의된 포트폴리오 후보 |
| 설치·수리 | 맞춤 목재 준비 | 절단·가공 과정 | 상담용 완료 기록 |

편집 구간: 청소 `24–28, 74–78, 138–142s`; 미용 `0.2–12.2s`; 설치 `0–4, 8–12, 16–20s`. 설치 영상은 완성 선반 설치가 아니라 설치 전 맞춤 부재 가공 장면이다.
